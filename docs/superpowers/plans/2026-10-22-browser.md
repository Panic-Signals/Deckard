# Browser and Saving Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Maschine's browser (LIBRARY and FILES tabs, software and MK3 BROWSE) over NI's library index and DECKARD's own, and saving sounds, groups and plug-in presets in Maschine's formats with tags.

**Architecture:** A new `deckard-library` crate owns the indexes and queries (NI's `komplete.db3` read-only, DECKARD's `library.db3`). `mxprj` learns the files' tag block (`SoundInfo2`); `deckard-doc` learns to write and load `.mxsnd`/`.mxgrp`/`.mxinst`/`.mxfx`. The viewer app draws the panel and does the loading; the Lua host gives NI's BROWSE scripts the browser model and passes LOAD back as a `BrowseCall`, as `SamplingCall` does.

**Tech Stack:** Rust (via `mise exec -- cargo`), `rusqlite` (feature `bundled`), egui, mlua.

**Spec:** `docs/superpowers/specs/2026-10-22-browser-design.md`

## Global Constraints

- Never write to NI's database, NI's library folders, or NI's favourites; open `komplete.db3` with `SQLITE_OPEN_READ_ONLY` (WAL honoured; never `immutable=1`).
- Never copy, bundle or redistribute NI content; no NI code ported (file layouts and schemas are data).
- Tests never touch the real library folders, NI's database or the settings file: fixtures and outputs in temp dirs. Tests that read the user's installed content skip themselves when it is absent.
- Run cargo through mise: `mise exec -- cargo …`, `mise run test`, `mise run lint`. `mise run check-platforms` must still pass (Linux, Windows).
- Commits only when the user asks for them; each commit step below means "stage; commit if the user has asked". Messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- The user's own folders are not indexed: FILES is a plain folder browser.
- Saves go to Maschine 3's user directory, `~/Documents/Native Instruments/Maschine 3/{Sounds,Groups,Plug-ins}` (Windows: the user's Documents, same subpath) unless Save As picks another folder.
- Save with Samples copies samples into `<name> Samples` beside the file, referenced relatively.
- The panel must open instantly with 50 000 items: queries run off the UI thread; the result list is virtualised (`ScrollArea::show_rows`).

## Review Focus

1. **Maschine rescanning while DECKARD reads** (`SQLITE_BUSY`, WAL growing): the browser keeps its last results and shows a quiet status, never panics. Test in Task 2 (`busy_index_keeps_last_results`).
2. **An indexed file that no longer exists** (pack moved, sample deleted): the row loads nothing and the status bar names the missing file. Test in Task 7 (`missing_result_reports_and_loads_nothing`).
3. **Non-ASCII names and tags** (UTF-16 in SoundInfo2, "Café Ésprit", "Ambient › 空"): round-trip exactly. Test in Task 1 (`non_ascii_tags_round_trip`).
4. **Saving onto an existing file** (same name in the same folder): Save asks before overwriting; Save of an already-saved item overwrites silently. Test in Task 9 (`save_as_existing_name_asks`).
5. **Loading a group file whose samples live in a library elsewhere** (factory `.mxgrp` from `/Users/Shared/...`): its samples resolve through the existing `deckard_engine::library::Resolver` and play. Test in Task 5 (`factory_group_loads_with_its_samples`).

### Task 1: The tag block in Maschine files (`mxprj`)

Layout (read from `Velvet Lounge Library/Sounds/Drumsynth/OpenHH Zikmodo.mxsnd`, frame 108 payload; `wstr` = u32 count of UTF-16 units + units; all LE):

```text
u32 1                      (the NISD/108 version prefix; absent in the embedded scoped_ptr copy)
u32 2, u32 1
wstr ×6                    "", name, author, vendor, comment, ""   (field 0 and 5: keep as read)
u64 date                   u64::MAX = none
u32 ×5, u32                0,0,0,0,0, 1   (keep as read)

u32 n, wstr ×n             types: ["\:Drumsynth", "\:Drumsynth\:Hihat Open"]  ("\:"-joined levels, each level listed)

u32 n, (wstr, wstr) ×n     properties: "\@color", "\@devicetypeflags", "\@soundtype", "\@tempo", "\@verl", "\@verm", "\@visib"
```
