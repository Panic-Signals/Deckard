# Controller bugs

Bugs in the controller layer (`crates/surface/`, `apps/viewer/src/controller.rs`, the MK3's
pages and modes), logged while it's being built. Everything else goes in `docs/BUGS.md`;
what Maschine's controller has and DECKARD's lacks belongs in `docs/PARITY.md`. Pages are
described in `docs/controller-*.md`.

Numbered **C1**, **C2**, … so they never clash with `docs/BUGS.md`'s numbers.

Priority: **P0** = blocks use or loses work; **P1** = wrong, worked around; **P2** =
annoying; **?** = not yet triaged. Area: the mode or page (Browse, Plug-in, Mixer, Channel,
Steps, Song, Keyboard, Pads, Sampling, …), or display, LEDs, surface (the layer itself),
MK3 (the hardware/USB).

When one's fixed, move it to **Fixed** with the commit.
