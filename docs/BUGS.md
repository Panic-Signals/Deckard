# Bugs

Known bugs, and things that mustn't be lost track of, waiting to be prioritized. What
Maschine has and DECKARD lacks belongs in `docs/PARITY.md`, enhancements beyond Maschine
in `docs/FEATURES.md`; this is for what's broken or loose.

Priority: **P0** = blocks use or loses work; **P1** = wrong, worked around; **P2** =
annoying; **?** = not yet triaged. Area: software, MK3, engine, doc (file format),
lua-host, player, build.

When one's fixed, move it to **Fixed** with the commit.
