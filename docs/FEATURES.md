# Feature enhancements

Things DECKARD should do beyond Maschine, waiting to be prioritized. What Maschine has and
DECKARD lacks belongs in `docs/PARITY.md`; what's broken, in `docs/BUGS.md`.

Priority: **P0** = next; **P1** = soon; **P2** = some day; **?** = not yet triaged.
Area: software, MK3, engine, doc (file format), lua-host, player, build.

When one ships, move it to **Done** with the commit.
